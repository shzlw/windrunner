# Configuration

{/* TODO: one table per group, generated/checked against application.properties */}

Environment variables and properties for self-hosters.

- Database connection
- LLM providers: OpenAI, Gemini, Claude (API keys, base URLs, models, limits)
- Server settings: port, graceful shutdown, compression
- Authentication cookie settings
- MCP server enable/disable (`WINDRUNNER_MCP_ENABLED`, default `true`) — see [MCP server](mcp)
- OpenAPI/Swagger exposure (`WINDRUNNER_OPENAPI_ENABLED`)
