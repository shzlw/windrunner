# Quick start

Windrunner starts with a question. Add workspace context only when you need it.

## 1. Open Home

After signing in, open Home and ask a question such as:

> What needs my attention today?

Suggested prompts fill the input without sending it.

## 2. Continue in Ask AI

Your question opens in Ask AI. Use the sidebar to switch between conversations
or start a separate chat for a new topic.

## 3. Add context when needed

Add a project, team, user, or work item when the question needs a specific
source. Opening Ask AI from a workspace page also provides that page as
context. If a project-specific question has no project selected, Ask AI asks
you to choose one instead of guessing.

## 4. Ask AI to create or update work

Ask AI can draft or update work items, entries, and relationships. Proposals
appear in the project workspace for review; they do not change data until you
accept them.

## 5. Work directly in the workspace

Use Projects to organize work, Teams and Users for people context, and My Work
for items assigned to you. See [Using AI assistance](../guides/ai-assistance)
for AI actions.
