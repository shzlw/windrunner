# How Windrunner works

Windrunner separates durable work from the context around it:

| Building block | Purpose |
| --- | --- |
| Project | Workspace for related work. |
| Work item | A task, question, approval, review, or decision. |
| Entry | An update, answer, evidence, proposal, or resolution attached to a work item. |
| Relationship | A typed connection such as a blocker or dependency. |
| User and team | People who own, contribute to, or access work. |
| Conversation | A user-owned Ask AI session with optional workspace context. |

## A simple workflow

1. Create a work item for the outcome or question.
2. Add entries as the work develops.
3. Add relationships when a dependency, blocker, or supporting connection is important.

For example, use a `QUESTION` work item, add `EVIDENCE` and `ANSWER` entries,
then mark the answer as accepted.

Ask AI can read these records, summarize them, and suggest changes. Proposals
remain available for review until a person accepts or rejects them.
