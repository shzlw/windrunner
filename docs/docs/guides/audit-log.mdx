# Audit log

Audit Logs help administrators see what changed, when it changed, and who did
it. The page is available to admins and superadmins from Administration.

Search the list, move through pages, and select an entry to view its time,
action, entity, project, actor, outcome, summary, and any available before,
after, or field-change data.

The log can include changes to projects, work items, entries, relationships,
users, teams, API keys, and authentication. The workspace inspector also shows
history for the selected work item; that view is limited to one item.
