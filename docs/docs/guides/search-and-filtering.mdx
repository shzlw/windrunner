# Searching and filtering

Search is page-specific, not a global search. It narrows the records currently
shown without changing them.

Projects, Teams, Users, My Work, and Audit Logs each have their own search.
My Work also filters by project, status, and priority. Lists may be paginated,
so search each page of results when reviewing a larger set.

Use Ask AI for an answer, summary, comparison, or explanation across accessible
workspace records. Use page search when you need exact visible-record results.
